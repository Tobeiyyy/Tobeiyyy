# Hey, I'm Tobe 👋

Business Informatics student in Salzburg. I build the tools I use every day with Claude, and publish the ones that hold up for other people too.

## What I'm working on

### [FLIP Prompt Architect](https://github.com/Tobeiyyy/FLIP-prompt-architect)

A meta-prompt framework for Claude that interviews you before it builds anything. It routes your idea to the right artifact class — one-shot prompt, persistent assistant, skill, pipeline blueprint, coding-agent brief, or "just use the tool you already have" — and refuses to guess when it doesn't understand yet.

Built it because most prompt generators answer before they listen. This one does the opposite.

### [Kanryo](https://github.com/Tobeiyyy/kanryo)

A kanban board for one person that every Claude surface can read and write over MCP: chats on my phone, chats on my PC, and Claude Code. It runs free on Cloudflare Workers and D1 and is the project memory behind everything else I build. New ideas land in a "to review" column, which really means "talk this through with Claude first".

### [Afterwatch](https://github.com/Tobeiyyy/afterwatch)

Turns YouTube videos into structured notes in Obsidian (or Markdown, Word, Notion). One note per video, topic hubs that compare what different videos say about the same thing, and a backfill that works through a whole watch history from Google Takeout. Runs on any OpenAI-compatible model or a signed-in Claude Code CLI.

### [apple-music-discog](https://github.com/Tobeiyyy/apple-music-discog)

One Apple Music playlist per artist with their whole discography in release order: every album, EP and single, each recording exactly once, deluxe editions merged, live and clean duplicates dropped. A weekly updater adds new releases. Plain Python, nothing to install.
