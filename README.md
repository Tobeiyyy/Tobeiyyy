## What I'm working on

### [FLIP Prompt Architect](https://github.com/Tobeiyyy/FLIP-prompt-architect)

A meta-prompt framework for Claude that interviews you before it builds anything. It routes your idea to the right artifact class — one-shot prompt, persistent assistant, skill, pipeline blueprint, coding-agent brief, or "just use the tool you already have" — and refuses to guess when it doesn't understand yet.

Built it because most prompt generators answer before they listen. This one does the opposite.

### [Kanryo](https://github.com/Tobeiyyy/kanryo)

A kanban board for one person that every Claude surface can read and write over MCP: chats on my phone, chats on my PC, and Claude Code. It runs free on Cloudflare Workers and D1 and is the project memory behind everything else I build. New ideas land in a "to review" column, which really means "talk this through with Claude first".
